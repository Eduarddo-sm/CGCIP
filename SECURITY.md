# Security Policy

## Supported version

Only the latest commit on `main` is supported.

## Reporting a vulnerability

Do not open a public issue containing credentials, personal data, customer
records, screenshots of production environments, or exploit details. Contact
the repository owner privately through the GitHub profile and include only the
minimum information needed to reproduce the issue.

## Demonstration data

This public edition must contain synthetic data only. Pull requests and issues
that accidentally include operational data, `.env` files, database dumps,
spreadsheets, attachments, certificates, or access tokens will be closed and
their history rewritten when necessary.
